## Architecture

**Section heading:**
## A codebase you can reason about.

Magna is built on a contemporary PHP framework foundation with a deliberately focused core. No twenty-year compatibility layer, no archaeology required to understand a request's path through the system.

- **Focused core** — content management, done properly, and nothing else baked in
- **Clear boundaries** — core, plugins and your custom code stay separate by design
- **Framework conventions** — if you've worked in a modern framework, you already know your way around

---

## Extensible Plugin System

**Section heading:**
## Extend the platform. Don't patch it.

Plugins are the supported way to add functionality — with defined extension points, not core hacks.

- Add features without modifying core code
- Keep customisations upgrade-safe and version-controlled
- Package functionality for reuse across projects
- Ship specialised solutions on a stable foundation

If the extension you need doesn't exist, the architecture assumes you'll build it — and treats that as the normal path, not the exception.

## APIs and Integrations

**Section heading:**
## A CMS that plays well with the rest of your stack.

Websites live inside ecosystems — CRMs, payment systems, analytics, internal services. Magna is designed for programmatic access and integration work, so connecting it to the rest of your stack is engineering, not archaeology.

*API surface and reference live in the documentation — current, versioned, and honest about what's shipped versus in development. We don't document endpoints that don't exist yet.*

## Development Workflow

**Section heading:**
## Work the way you already work.

- **Version control friendly** — your customisations are code, in your repository
- **Environment-based development** — local, staging, production, as you'd expect
- **Custom content types and functionality** — first-class development targets
- **Open source** — read the code, trace the behaviour, contribute back

No opaque black boxes between you and the platform you're responsible for.
